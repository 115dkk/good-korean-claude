# good-korean-claude

Claude가 쓰는 한국어에서 번역투를 덜어 내는 Claude Code 플러그인입니다. 글쓰기 스타일 '체계적 추론자 v4'와 서로 다른 훅 세 개가 들어 있습니다. 하나는 파일에 들어가기 직전의 한국어 문장을 그 스타일의 규칙과 대조하고, 하나는 한국어 마크다운에 em-dash가 들어가지 못하게 하고, 나머지 하나는 Claude의 마지막 답변이나 Claude가 사용자에게 보내는 질문에 em-dash가 있거나 거의 영어로 되어 있으면 다시 쓰게 합니다.

## 설치

Claude Code에서 다음 두 명령을 차례로 실행하십시오.

```
/plugin marketplace add 115dkk/good-korean-claude
/plugin install good-korean-claude@korean
```

## 들어 있는 것

### 스타일 `chegyejeog-chulonja-v4-style`

답변을 쓰기 전에 정리할 것, 한국어 문장 규칙, 형식, 분량과 구성, 창작물을 다루는 법을 정한 글쓰기 스타일입니다. 한국어 규칙에는 번역투 판정 기준, 물리·계량 은유, 문장 구조, 피동과 해석, 특정 용법, 어휘가 들어 있습니다.

이름을 대고 부를 때만 적용되고, 한 번 부르면 사용자가 다른 스타일을 요청할 때까지 대화 전체에 적용됩니다.

```
/good-korean-claude:chegyejeog-chulonja-v4-style
```

### 번역투 판정 훅

Write, Edit, MultiEdit가 파일을 쓰기 직전에 돌아갑니다. 편집이 새로 들이는 줄 가운데 한글이 든 줄과 그 앞뒤 세 줄 안의 새 줄을 모아, 사용자의 `claude` CLI로 Claude Sonnet 5.5(effort medium)를 불러 스타일 2장 '한국어'의 규칙과 대조하게 합니다.

- 규칙에 분명히 걸리는 표현이 있으면 편집을 거부합니다. 거부 사유에는 걸린 표현, 어긴 규칙, 고친 말이 들어 있고, Claude는 그것을 보고 고쳐 쓴 뒤 다시 편집합니다.
- 걸리는 표현이 없으면 편집이 그대로 진행됩니다. 한글이 없는 편집, `~/.claude`와 `~/.codex` 아래 파일, 잠금 파일, 저장소의 `.hookignore`에 적힌 파일은 모델을 부르지 않고 바로 통과합니다.
- 판정 모델을 부르지 못하면(PATH에 `claude`가 없거나, 시간이 초과되거나, 오류가 나면) 편집은 그대로 진행되고, 판정하지 못했다는 사실을 Claude에게 알립니다.

판정할 때마다 모델을 한 번 부르므로 편집 한 번에 5~10초가 더 걸리고, 사용량은 쓰고 있는 Claude 요금제에서 나갑니다.

#### 판정하지 않을 파일 정하기

일부러 틀린 문장을 넣은 테스트 입력이나 다른 글을 그대로 옮겨 온 자료처럼 판정하면 안 되는 파일이 있으면, 저장소 루트에 `.hookignore`를 만들고 그 경로를 적으십시오. 문법은 `.gitignore`와 같아서 주석(`#`), 부정(`!`), 디렉터리만 가리키는 끝의 `/`, 몇 단계든 건너뛰는 `**`를 쓸 수 있습니다.

```gitignore
# 번역 원문을 그대로 옮긴 자료
docs/sources/
# 일부러 틀린 문장을 넣은 테스트 입력
**/fixtures/*.ko.txt
```

훅은 편집하는 파일이 든 git 저장소의 루트에 있는 `.hookignore` 하나만 읽고, 하위 디렉터리에 둔 `.hookignore`는 읽지 않습니다. git과 마찬가지로 디렉터리를 통째로 제외하면 그 안의 파일을 `!`로 다시 판정 대상에 넣을 수 없습니다. 이 파일은 판정 모델을 부르는 훅에만 적용되므로 em-dash 금지 훅과 답변·질문 훅은 `.hookignore`와 상관없이 돌아갑니다. make-interfaces-feel-better 플러그인의 화면 문구 판정 훅도 같은 `.hookignore`를 따릅니다.

### em-dash 금지 훅

Write와 Edit가 마크다운 파일(`.md`, `.markdown`, `.mdx`)을 쓰기 직전에 돌아갑니다. 새로 쓰는 텍스트에 em-dash(U+2014)가 있고 그 텍스트나 대상 파일에 한글이 있으면 편집을 거부합니다. 한국어에는 em-dash 용법이 없기 때문입니다. 거부 사유를 받은 Claude는 삽입절을 괄호로 처리하거나 문장을 나눠 다시 씁니다. 한글이 없는 영어 문서의 em-dash는 막지 않습니다.

### 한국어 답변과 질문 훅

Claude가 턴을 끝내려 할 때(Stop) 사용자에게 보이는 마지막 답변을 검사합니다. 다음 가운데 하나라도 해당하면 턴을 끝내지 못하게 막고 답변 전체를 다시 쓰게 합니다.

- em-dash(U+2014)나 줄표(U+2015)가 있습니다. 하이픈과 en-dash(U+2013)는 검사하지 않습니다.
- 단어 수로 센 영어 비율이 80% 이상입니다. 한글이 섞인 단어는 한국어로 셉니다.

코드블록, 인라인 코드, URL, 경로, 마크다운 링크, HTML 태그는 검사하기 전에 지우고, 인용(`>`) 줄은 em-dash를 찾을 때도, 영어 비율을 셀 때도 뺍니다. 그러니 영어 원문을 보여야 하면 인용이나 코드블록에 넣으면 됩니다. 같은 턴에서 세 번 막아도 고쳐지지 않으면 그 답변은 통과시킵니다.

Claude가 AskUserQuestion으로 질문을 보내기 직전에도 같은 기준으로 검사합니다. 질문마다 제목, 본문, 선택지 이름과 설명을 모아 검사하고(미리보기는 빼고), 기준에 걸리면 질문을 보내지 않은 채 Claude에게 고쳐 쓰게 합니다. 연달아 세 번 막아도 고쳐지지 않으면 그다음 질문은 보냅니다.

영어로 답해 달라고 한 대화에서도 이 훅은 답변과 질문을 막으므로, 그런 대화에서는 플러그인을 끄십시오.

### 세 훅이 돌아가는 조건

스타일을 부르지 않아도 플러그인이 켜져 있으면 세 훅은 늘 돌아갑니다. 모델을 부르는 것은 번역투 판정 훅뿐이고, 나머지 둘은 바로 끝납니다. 세 훅 모두 `python3`가 PATH에 있어야 하고, 번역투 판정 훅은 `claude`도 있어야 합니다.
